# Trevas — sete propostas de artes

Estas sete imagens são propostas para aprovação visual, não arquivos instalados no grimório. Nenhum PNG de `grimorio_oficial/html/assets`, catálogo, CSS ou folheamento foi alterado para incluí-las.

1. Corte das Trevas
2. Lua Negra
3. Passo Sombrio
4. Ruptura Sombria
5. Fortaleza da Noite
6. Domínio das Trevas
7. Módulo de Voo

As cinco últimas páginas, seus nomes e descrições são propostas novas, sujeitas à aprovação. A identidade de Trevas foi preservada e a composição segue a referência até Cura: uma ilustração principal e três etapas de execução na outra folha. O selamento aparece apenas como pequeno elemento da arte.

A sequência é uma proposta completa para conferir o padrão antes de estendê-lo aos outros oito livros. As artes desses oito livros ainda não estão prontas. Nada deve ser integrado ao recurso antes da aprovação das artes e da conferência dos recortes, sem mudar a receita original.
